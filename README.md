# STAR PICKER｜メニュー・戦闘UIブランチ

RPGツクールMV製『STAR PICKER』の独自メニューと、監獄編で使うクエスト・資料収集・戦闘表示をまとめた開発版です。対象は `game_MV.zip` 内のプロジェクト（MVコア 1.6.1、メニュー v4.6）です。比較元のGitコミットは未指定のため、以下は収録機能と確認状況を示します。

## この版で試せること

| 入口 | 内容 |
|---|---|
| メニュー → 連携技 | 仲間を縦に選択し、専用枠で現在の設定技を確認・変更。技の保存先をマップ戦闘と共有する。 |
| メニュー → クエスト | メイン・サブ別に未開始・進行中・完了を管理し、現在の目的と履歴を読む。 |
| メニュー → 資料庫 | 人物・勢力・世界記録・調査資料を、イベントや探索に応じて段階解放する。 |
| メニュー → 詳細能力 | 仲間を切り替えて能力・装備・属性／状態異常の有効度・習得技を確認し、連携技設定へ移動する。 |
| マップ戦闘 | Tactical_Battleの出撃者からHP・MP・状態・設定技を取得する。このZIPでは全員一覧と操作キャラの顔パネルを表示する。 |

## 起動とデータ編集

1. MVで `Game.rpgproject` を開き、テストプレイを開始する。メニュー上部の目印は **v4.6**。
2. `js/plugins/StarPickerMenu.js` と同ディレクトリの `SP_*.js` 6本を一組で使う。メニューが起動時に各機能を初期化する。技設定は `Tactical_Battle.js` の戦闘処理と連携する。
3. クエストと資料の定義は `js/plugins/SP_RecordData.js`、整備票の略図は `img/pictures/SP_DemoDuct.png` にある。公開後の進行を維持するため、既存IDと段階の順序を保つ。

監獄編の排熱弁と整備票は仮データ。このZIPのイベントデータには、それらを進める直接の `SP QUEST`・`SP ARCHIVE` 命令を確認していない。試すには、マップ上に決定ボタンのテストイベントを作り、「プラグインコマンド」で下の命令を1行ずつ実行する。各段階でメニューを開くと変化が分かる。

| 命令 | 確認内容 |
|---|---|
| `SP QUEST vent 1` → 別のイベントで `SP QUEST vent 2` | 排熱弁の依頼開始と目的更新 |
| `SP QUEST vent COMPLETE` | 完了表示と履歴 |
| `SP ARCHIVE note 1` → 別のイベントで `SP ARCHIVE note 2` | 整備票の発見、本文更新と略図の表示 |

## ブランチ共有前に対応する点

- **戦闘BGMが欠けている。** `data/System.json` の `battleBgm.name` は `LICON_mix`。同名の音源がZIPに無く、戦闘開始時に読み込みエラーが起きうる。すぐに動作確認するなら、MVの「データベース → システム」で戦闘BGMを同梱済みの `Battle1` などに変更する。指定曲を使う場合は、その音源を用意する。
- **コンパクトHUD v1.2は別配布。** ZIP内の `SP_BattleHUD.js` は全員一覧を出す版。最新版をブランチに含める場合は同名ファイルをv1.2に差し替える。v1.2では戦術戦闘の全員一覧が初期状態で非表示になり、操作キャラを小型パネルに表示する。戦術戦闘の `LICON_mix` 指定時にはマップ曲を継続する。標準戦闘でも欠損音源を参照しないよう、BGM設定は別途確認する。
- **プラグイン登録を整理する。** `js/plugins.js` は21行・19種類で全行ON。`Community_Basic` と `CustomLogo` が各2回あり、後の行はパラメータが空。先の設定済み行を残す。`AltMenuScreen` もONで仲間欄を4列にするため、STAR PICKERのレイアウトを使う構成ではOFFを推奨。登録整理後はメニューと技設定を実機で確認する。
- **個人のプレイデータを除外する。** ZIPには `save/`（セーブ4件、設定など）と `js/plugins.js.backup_20261127_141322_666` が入っている。共有対象から外す。リポジトリ直下がこのプロジェクトなら、除外パターンは `/save/` と `/js/plugins.js.backup_*`。設定本体の `js/plugins.js` は共有する。
- **既存リポジトリのプロジェクト位置に合わせる。** 展開すると最上位は `game_MV/`。既存の `Game.rpgproject` がある階層に合わせて差分をステージする。ZIP本体は約381 MiBなので、ブランチには展開した変更ファイルを載せる。公開リポジトリへ画像・音源・第三者プラグインを追加する場合は、素材ごとの公開条件を確認する。

## 検証結果と残作業

| 項目 | 結果 |
|---|---|
| アーカイブと収録版 | ZIPのCRC検査に合格。メニューとSPモジュール6本はv4.6配布版と一致。 |
| メニュー・記録・戦闘の模擬テスト | ZIPから取り出したJSに対し、v4.6対応の別テストで連携技1件・設定変更、クエスト／資料進行と保存相当の復元、戦闘開始・終了に伴うHUD切替を確認。 |
| ZIP同梱の旧テスト | `node tests/smoke.cjs --tactical` は `Scene_Boot is not defined` で停止する。旧テストがv4.6の起動処理を模擬していないため、テスト側の更新が必要。`TEST.md` は旧版向け。 |
| MVでの通しプレイ | このZIPを使った実機確認は未実施。BGM設定後、戦闘開始→技選択→連携→戦闘終了、さらに資料取得→セーブ→再起動→ロードを確認する。 |
